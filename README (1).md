# EXQA 2027 website

Call for papers for EXQA 2027, co-located with FSE 2027 (Shenzhen, July 12–16, 2027).

## Deploy on GitHub Pages

1. Create a repository. For a URL like `https://exqa2027.github.io/`, create a GitHub organization named `exqa2027` and a repo named `exqa2027.github.io` (the same pattern OXAI 2026 uses). Any other repo name gives `https://<user>.github.io/<repo>/`.
2. Add `index.html`, `README.md`, and `.nojekyll` to the repo root and push.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site is live within a minute or two.
